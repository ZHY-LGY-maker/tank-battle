# 坦克大战 · Battle City

一个用纯 HTML + Canvas + JavaScript 实现的经典坦克大战（Battle City）小游戏，单文件即可运行，无需任何依赖。

## 🎮 试玩

- **在线体验**：https://`<你的用户名>`.github.io/`<仓库名>`/（启用 GitHub Pages 后）
- **本地运行**：直接用浏览器打开 `index.html` 即可。

## 🕹️ 操作

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 下一关 / 重新开始 |

移动端会自动显示触屏方向键与射击按钮。

## ✨ 特性

- 经典玩法：消灭 20 辆敌方坦克，保护你的基地（鹰徽）。
- 4 种敌人：普通 / 快速 / 强力 / 装甲（3 点生命）。
- 5 种地形：砖墙（可摧毁）、钢墙（需满级火力）、水域、草丛（隐蔽）、基地。
- 5 种道具：
  - ⭐ 火力升级（最高 3 级，满级可击穿钢墙）
  - 💣 清屏炸弹（摧毁场上所有敌人）
  - ❤️ 额外生命
  - 🛡️ 护盾（10 秒无敌）
  - ⛏️ 加固（12 秒内基地不可摧毁）
- 2 个关卡，通关后可继续挑战。
- 复古像素风 + 即时音效（Web Audio）。

## 🚀 部署到 GitHub Pages

1. 打开仓库 **Settings → Pages**。
2. 在 **Branch** 下选择 `main`，目录选择 `/ (root)`，点击 **Save**。
3. 稍等片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
